# 커스텀 스킨 제작 가이드 (캐릭터·노트)

캐릭터와 노트의 Spine 스킨을 바꾸는 법입니다. 둘은 **같은 파일 형식, 같은 로더, 같은 배율 관행**을 씁니다.
노트 스킨은 2026-11-11 씬 04 공식 곡(`0-18`)에서 실기 확인했습니다.

---

## ⚠️ 먼저 지킬 관행: 스킨 파일은 "원본의 절반 좌표", 모드는 "원본 배율 × 2"

**스킨을 새로 만들거나, 스킨을 읽는 코드를 고칠 때 반드시 이 짝을 지키십시오.**

| 쪽 | 하는 일 |
| --- | --- |
| 스킨 파일 (Spine 에디터) | 원본 `.skel`을 평소대로 가져와 작업합니다. 이 작업 흐름에서는 **좌표가 원본의 정확히 ½**이 됩니다. 가져오기·내보내기 배율을 따로 바꾸지 않습니다. |
| 모드 | 원본 에셋 `scale`의 **2배**로 읽습니다. 게임 원본은 캐릭터·노트 모두 `0.005`이므로 실제 값은 `0.01`입니다. |

비유하면 스킨 파일은 **반으로 축소 복사된 도면**이고, 모드는 그것을 **2배 확대해서 찍는 복사기**입니다. 둘을 같이 써야 원래 크기가 나옵니다.

- 캐릭터: `CustomSkinInjector.GetOrBuild`가 `0.01` 고정.
- 노트: `NoteSkinRules.RuntimeScale(원본 scale)` = 원본 × `HalfImportFactor`(2).

### 이 관행이 생긴 이유 (실제 사고)

노트 스킨을 처음 만들 때 "원본과 같은 배율(0.005)"로 읽게 했더니 **노트가 반 크기**로 나왔습니다(2026-11-11).
원본 `0411_road.skel`(게임 번들)과 스킨 JSON을 비교하자 모든 뼈대 위치가 정확히 ½이었습니다.

| 뼈대 | 원본 `.skel` | 스킨 JSON |
| --- | --- | --- |
| `body` | (11.22, 25.41) | (5.61, 12.70) |
| `fx` | (49.59, −39.31) | (24.79, −19.66) |
| `hp` | (0, 150) | (0, 75) |

캐릭터는 이 문제가 드러나지 않았습니다. 예전 spine skin 모드에서 가져온 캐릭터 주입기가 원본(0.005)의 2배인 0.01로 고정되어 있어,
반 좌표 스킨이 우연히 원래 크기로 나왔기 때문입니다. 그래서 노트도 같은 관행을 따르기로 했습니다.
(캐릭터 스킨 JSON이 원본의 ½인지 원본 캐릭터 `.skel`과 직접 대조하지는 않았습니다. 원본 scale과 증상으로 본 추정입니다.)

### 하지 말 것

- **Spine 데이터 가져오기 배율을 2로 바꿔 "원래 크기" 스킨을 만들기**: 모드가 다시 2배 하므로 **2배 크기**로 나옵니다.
- **모드 쪽 배율을 원본 그대로(×1)로 바꾸기**: 기존 캐릭터·노트 스킨이 전부 반 크기가 됩니다.
- **`팩 설정`의 배율로 크기를 맞추기**: 그림 해상도만 바뀌고 노트·캐릭터 크기는 그대로입니다.

배율 관행을 바꿔야 할 일이 생기면 캐릭터·노트를 **함께** 바꾸고, 이미 만든 스킨을 모두 다시 내보내야 합니다.

---

## 1. 파일 배치

게임 루트 `skin test/` 아래에 **종류별로** 나눠 둡니다. 캐릭터는 `skin test/character/{세트 이름}/`, 노트는 `skin test/note/{세트 이름}/`.
세트 폴더 안에 `{세트 이름}.json`·`.atlas`·`.png`. 세 파일 이름과 폴더 이름이 모두 같아야 합니다.

```text
H:\muse dash hwa\skin test\
├── character\
│   └── char_1_rock\char_1_rock.json / .atlas / .png      # 캐릭터 (이름 고정 5종)
└── note\
    ├── 0411_road\0411_road.json / .atlas / .png          # 노트 (원본 스켈레톤 이름)
    └── 0411_air\0411_air.json / .atlas / .png
```

- 모드가 시작할 때 `character/`·`note/`와 캐릭터 세트 5종의 빈 폴더를 만듭니다.
- **옛 배치**(`skin test/{세트 이름}/`, 2026-11-11 이전)도 계속 읽습니다. 새 위치에 같은 세트가 없을 때만 쓰고,
  로그에 `옛 위치(...)에서 읽었습니다`가 세트마다 한 번 남습니다. 둘 다 있으면 새 위치가 이깁니다(`SkinFolderRules`).
- 노트 세트를 `character/`에 넣으면 읽지 않습니다(반대도 마찬가지). 종류 폴더는 섞지 않습니다.

| 종류 | 세트 이름 | 바뀌는 대상 |
| --- | --- | --- |
| 캐릭터 | `char_3_black`, `char_1_sleepy`, `char_1_rock`, `char_1_rampage`, `char_3_violin` (코드에 고정) | 해당 캐릭터의 배틀 오브젝트와 고스트(그림자 제외) |
| 노트 | **원본 스켈레톤 이름**. 게임의 `0411_road_SkeletonData`면 `0411_road` | 그 스켈레톤을 쓰는 모든 노트 프리팹(속도 1·2·3 등) |

- 노트 스킨은 **크리스마스 곡에만** 적용됩니다: `info.txt`에 `크리스마스 … = 활성화`(또는 `true`)를 둔 커스텀 곡, 또는 MelonPreferences `ForceChristmas`를 켠 때.
  그 밖의 곡(공식 곡 포함)은 원본 노트입니다. 로그 `[NoteSkin] 크리스마스 곡이라 노트 스킨을 씌웁니다`로 확인합니다(2026-11-11 변경, 그전엔 모든 곡).
  캐릭터 스킨은 이 조건과 상관없이 모든 곡에 적용됩니다.
- 켜고 끄기는 MelonPreferences의 `EnableSpineSkin` 하나입니다.
- 게임 실행 중에 노트 스킨 파일을 고치면 다음 곡을 로딩할 때 다시 읽습니다. 캐릭터 스킨은 게임을 다시 켜야 합니다.

## 2. 만드는 순서

1. AssetStudio류 도구로 게임 번들에서 원본 스켈레톤(`.skel`)과 그림을 뽑습니다.
   노트는 `gamescene_{씬번호}_assets_all_*.bundle`에 있습니다(예: `0411_road`는 `gamescene_04`).
2. Spine **3.8** 에디터로 원본을 가져옵니다. **배율은 손대지 않습니다**(위 관행).
3. 그림을 고칩니다. **애니메이션 이름은 지우거나 바꾸지 않습니다**(아래 3절).
4. **JSON**으로 내보냅니다(텍스처 아틀라스: 팩 → 어태치먼트). 바이너리(`.skel`)로 내보내면 모드가 읽지 못합니다.
5. 내보낸 세 파일을 캐릭터면 `skin test/character/{세트 이름}/`, 노트면 `skin test/note/{세트 이름}/`에 넣습니다.

### 파일 이름을 바꾸고 싶을 때

내보낸 파일 이름은 Spine 트리 맨 위의 **스켈레톤 이름**에서 나옵니다. 거기서 바꾸고 다시 내보내는 것이 안전합니다.
파일만 직접 바꿨다면 `.atlas`의 첫 페이지 줄(`0411_road.png`)도 맞춰야 합니다. 모드는 텍스처 이름을 이 줄에서 얻습니다
(`NoteSkinRules.AtlasTextureName`). 맞지 않으면 `Could not find matching atlas page in the texture array`로 실패합니다.

## 3. 애니메이션 이름 (노트의 액션 계약)

노트 프리팹은 `actionData`에 적힌 이름으로 애니메이션을 부릅니다(`in` → `in_nor_44`, `note_out_p` → `out_p` 등).
스킨에 그 이름이 하나라도 없으면 모드는 **그 노트에는 스킨을 씌우지 않고** 로그를 남깁니다.

```text
[NoteSkin] 0411_road: 프리팹 '...'이(가) 부르는 애니메이션이 없어 원본 노트를 씁니다: out_p
```

프리팹별 이름 표는 [NOTE_SKIN_INJECTION.md](../experiments/NOTE_SKIN_INJECTION.md) 2절에 있습니다.

## 4. 로그로 확인하기

```text
[CustomSkinInjector] note:0411_road 커스텀 SkeletonDataAsset 생성 완료 (scale 0.01)
[NoteSkin] 노트 스킨 주입 1개째 (0411_road, 041102_road_nor_2)
```

- `scale 0.01`이 아니면 배율 관행이 깨진 것입니다(씬 04·05 노트 기준).
- 노트가 반 크기·2배 크기로 나오면 위 관행부터 의심하십시오.
- `생성 완료` 줄 없이 `[ERROR] ... 예외`가 있으면 파일 형식이나 아틀라스 페이지 이름을 보십시오.
