# 노트 dt 권장표와 차터 허용 범위

채보 WAV 이름의 `_dt`에 적는 값의 **권장표**와, 차터가 권장표를 벗어나 조절할 수 있는 **허용 범위**입니다.
그리고 `hwa info.txt` 한 줄로 dt를 권장표에 자동으로 맞추는 방법을 설명합니다.

- 작성일: 2026-10-25, 게임 6.7.0
- 값의 근거(실기 측정 기록): [HOLD_BAR_LENGTH_DT.md](../experiments/HOLD_BAR_LENGTH_DT.md) 1절, [NOTE_SPEED_DT.md](../experiments/NOTE_SPEED_DT.md) 4절
- 속도는 dt가 아니라 uid `yy`로 정해집니다(`yy` 01/02/03 = 지상 기본 속도 1/2/3, 04/05/06 = 공중 기본 …).
  dt는 그 속도에 맞춰 적습니다.

---

## 1. 권장표 (2026-10-25 전 계열 실기 확정)

| 노트 계열 | 속도 1 (느림) | 속도 2 (보통) | 속도 3 (빠름) | 실기 검증 상태 |
| --- | --- | --- | --- | --- |
| 일반 / 트랩 / 음표 / Up·Down | 1.48 | 1.28 | 1.16 | 실기 검증 완료(정답 확정) |
| 홀드(롱노트) | 1.47 | 1.26 | 1.10 | 실기 검증 완료(꼬리 렌더 오차 0ms) |
| 보스 발사체 | 0.8 | 0.76 | 0.6 | 실기 검증 완료(정답 확정) |
| 고정 이벤트: 씬 전환(`0004yy`) / 보스 액션(`0101xx`) | 0 | 0 | 0 | 속도와 무관 |

## 2. 차터 허용 범위

권장표는 정답이지만 강제는 아닙니다. **일반 계열은** 차터가 아래 범위 안에서 숫자를 골라도 됩니다.

| 속도 | 권장 | 허용 범위 |
| --- | --- | --- |
| 1 | 1.48 | 1.48 (고정, 범위 없음) |
| 2 | 1.28 | 1.18 ~ 1.38 |
| 3 | 1.16 | 0.98 ~ 1.28 |

- 범위는 **일반 계열(일반 / 트랩 / 음표 / Up·Down)에만** 있습니다.
- **홀드·보스 발사체·고정 이벤트는 권장값 그대로** 쓰십시오. 홀드는 게임이 막대 길이를 속도별 고정 시간
  (44 / 38 / 33프레임)으로 그려서, `_dt`가 권장값과 다르면 꼬리가 판정 시각과 어긋납니다
  ([HOLD_BAR_LENGTH_DT.md](../experiments/HOLD_BAR_LENGTH_DT.md) 2절).

## 3. 그러면 이렇게 하면 됩니다

차터가 할 일은 둘 중 하나입니다.

### ① 권장표를 그대로 쓰고 싶다 → `hwa info.txt`에 한 줄

```text
// 권장 표로 dt를 덮어써서 정상적으로 하게 해줍니다.
dt를 권장 표로 고치기 = 활성화
```

- 켜면 모드가 노트마다 계열과 uid 속도를 보고 **WAV `_dt`를 무시하고 1절 권장값으로 덮어씁니다.**
  WAV 이름에 `_dt`를 안 적었거나 잘못 적었어도 권장값이 들어갑니다.
- 로그에 `[ExperimentChart.Dt] 'dt를 권장 표로 고치기' 활성화: 권장값으로 바꾼 노트 N개`가 남습니다.
- 키는 `권장표` / `권장 dt` / `dt 보정` / `fix dt` / `recommended dt` 중 하나가 들어가면 됩니다.
  값은 `활성화`/`비활성화` 외에 `true`/`false`, `on`/`off`, `켜기`/`끄기`, `1`/`0`도 됩니다.

### ② 숫자를 직접 조절하고 싶다 → 줄을 안 적거나 `비활성화`

```text
dt를 권장 표로 고치기 = 비활성화
```

- 이때 모드는 **WAV `_dt`를 그대로** 씁니다(이전과 같은 동작).
- 대신 2절 범위를 벗어난 WAV가 있으면 곡을 불러올 때 경고로 알려 줍니다. 값은 바꾸지 않습니다.

  ```text
  [ExperimentChart.Dt] 권장 범위 밖 dt: uid=051002, 일반 속도 2, _dt1.45 (허용 1.18~1.38) × 12개
  [ExperimentChart.Dt] 권장 범위 밖 dt: uid=050203, 홀드 속도 3, _dt1.07 (허용 1.1) × 4개
  ```

  같은 uid·dt 조합은 한 줄로 묶고, 20종이 넘으면 나머지는 생략합니다.

## 4. 권장표가 손대지 않는 노트

아래 노트는 실기 확정값이 없어서, 옵션을 켜도 **WAV `_dt`(또는 모드 기본값)를 그대로** 씁니다. 범위 경고도 하지 않습니다.

| 노트 | 이유 |
| --- | --- |
| 샌드백(`xx=04`) | 실측값 없음 |
| 보스 톱니(`xx=09`) | 공식 곡(OBLIVION, 속도 2)에서 0.667로 발사체와 같아 보였지만 실기 확정값 없음 |
| 속도 자리가 없는 uid(`yy`가 01~18 밖) | 속도를 알 수 없음 |

하트(`0002yy`)와 고스트(`xx=17`)는 일반 계열로 봅니다.
