### 1.1 `30dff77`(v0.14.1, 홈↔곡 선택 BGM) 재검토

고친 내용 자체는 맞습니다. 남겨 둔 관찰 두 가지:

- **커스텀 → 공식 곡으로 넘길 때 주입 클립을 은퇴시키지 않습니다.** `TriggerMenuBgmChange`가 공식 곡 uid를 받으면 상태만 지우고 `injectedMenuClip`은 그대로 둡니다. 다음 커스텀 곡 주입이나 `StopCustomMenuBgm`에서 은퇴하므로 **최대 1개 클립**만 남고 늘지 않습니다. 실기 확인된 경로라 건드리지 않았습니다.
- **`isMenuPanelActive`를 내리는 곳은 `PnlStage`/`PnlPreparation`의 `OnEnable`과 씬 리셋뿐입니다.** 홈에서 곡 선택을 거치지 않는 새 화면 경로가 생기면(게임 업데이트) 곡 선택 판정이 계속 거짓으로 남을 수 있습니다. 증상은 "커스텀 미리듣기가 안 나옴"이고 크래시는 아닙니다.
- `AudioManager_PlayBgm_Patch`의 커스텀 클립 판정은 주입 클립 참조가 우선이고, 이름이 `.ogg`로 끝나는지는 보조입니다. 번들에서 읽은 Unity 클립 이름에는 보통 확장자가 붙지 않으므로 지금은 문제가 되지 않을 것으로 봅니다(이번에 실측하지는 않았습니다).

## 3. 업데이트 내성 감사와 고친 것

### 3.1 이미 있는 장치 (확인만)

- `PatchInstaller`: 패치 메서드를 미리 JIT 해 보고, 컴파일 안 되거나 대상이 사라진 패치는 걸지 않음. 다중 대상 클래스는 남은 대상만 부분 적용.
- `PatchHealthCheck`: 대상 해석 결과를 시작 시 요약. 타입이 사라져도 클래스마다 격리.
- `FeatureGuard`: 매 프레임 기능 10회 연속 실패 시 자동 비활성, 씬 전환 때 재무장.

이 셋은 **"메서드가 사라진 업데이트"** 를 잡습니다. **"메서드는 그대로인데 동작이 바뀐 업데이트"** (6.7.0의 `BGM_OneShot` 사고)는 아무 경고도 남지 않았습니다.

### 3.2 게임 버전 경고 추가 — `GameVersionCheck`

- 위치: [GameVersionCheck.cs](../../muse%20dash%20test/Core/GameVersionCheck.cs), 호출은 [MainMod.cs](../../muse%20dash%20test/MainMod.cs) `PatchHealthCheck.Run()` 바로 뒤.
- `Application.version`을 검증 버전 `6.7.0`과 숫자로 비교합니다(`6.10.0` > `6.7.0`, `6.7` = `6.7.0`). 같으면 `[GameVersion] 게임 6.7.0 (검증 버전과 같음)` 한 줄, 다르면 경고 한 줄입니다. **기능은 끄지 않습니다.**
- 새 게임 버전에서 실기 검증을 마치면 `VerifiedGameVersion`을 함께 올리십시오. 테스트 9개(`GameVersionCheckTests`).

### 3.3 예외가 게임 흐름으로 새던 패치

Harmony Prefix/Postfix에서 던진 예외는 게임 원본 메서드의 호출자에게 그대로 올라갑니다. `try` 없이 다른 함수를 부르는 패치를 전수 스캔해(32개) 위험한 것만 감쌌습니다.

| 패치 | 위험 | 조치 |
| --- | --- | --- |
| `StageBattleComponent.End` Postfix | `StopMedia` 앞부분(`ProgressBarPatch.Reset`, `HwaSyncManager.ResetCache`)이 자체 `try` 밖. 던지면 게임의 배틀 종료 흐름이 끊김 | `Exit`/`Release` Postfix와 같은 모양으로 감쌈 |
| `StageBattleComponent.Pause`/`Resume`/`InitData` Postfix | 로그 문자열 보간과 위임 호출이 감싸져 있지 않음 | 감쌈 |
| `MusicInfo.GetLocal` Prefix | 곡 목록을 그릴 때마다 불림. 던지면 UI 갱신이 끊김 | 감싸고 첫 1회만 기록, 원본 조회로 넘김 |
| `DBConfigLocalALBUM.GetLocalAlbumInfoByIndex` Prefix | 같음 | 같음 |

남긴 것(위임 대상이 자체 `try`를 갖거나 본문이 필드 비교뿐인 것): `ChangeHealthValue` 4종(`HywHpText.Apply`), `AudioSource.PlayOneShot` 2종(`ShouldPlayOneShot`), `SaveDataManagerPatch` Postfix(`SetUnlockAllMaster`), `IsIgnoreCurrentNoteChecking` 2종, `DisableUpdateNoticePatch`, `InputOverlay.Patches`, `PnlHomeDebugPatch`, `ChristmasFestival`의 `isChristmas` getter.

스캔 방법: Prefix/Postfix/Finalizer 본문에 `try`도 `FeatureGuard`도 없는 것을 찾았습니다. 다음 감사에서 같은 스캔을 다시 돌리면 새로 생긴 것만 보면 됩니다.
